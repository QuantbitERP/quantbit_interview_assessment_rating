# Quantbit Interview Assessment Rating

Interview Assessment and Intern Performance Rating Management Module for Frappe / ERPNext.

---

### Installation

You can install this app on your Frappe Bench using the following commands:

```bash
cd $PATH_TO_YOUR_BENCH
bench get-app [https://github.com/shravan-kolekar/quantbit_interview_assessment_rating.git](https://github.com/shravan-kolekar/quantbit_interview_assessment_rating.git)
bench --site [your-site-name] install-app quantbit_interview_assessment_rating
bench --site [your-site-name] migrate
